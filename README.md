# AI Portrait Telegram Bot

Telegram-бот для создания AI-портретов с переносом художественного стиля.

## Описание

Приложение предназначено для высокоточного переноса художественного стиля и композиции с одного изображения (образца) на фотографию конкретного человека. Основная цель — создать "шедевр", который выглядит как оригинальное произведение искусства, но с сохранением 100% узнаваемости человека.

## Миссия

Предоставить пользователям инструмент для превращения селфи в профессиональные портреты, стилизованные под любую эпоху, технику или фантастический мир, без необходимости использования сложных графических редакторов.

## Алгоритм работы

1. **Анализ образца**: Подробный анализ изображения-образца, включая:
   - Определение общей стилистики (фото/иллюстрация/рисунок/3D)
   - Описание технических деталей (объектив, краски, текстуры)
   - Анализ композиции и формата
   - Описание позы, одежды, окружения, настроения

2. **Анализ человека**: Детальный анализ фотографии человека:
   - Пол, возраст, этническая принадлежность
   - Черты лица (форма лица, глаза, нос, губы, подбородок)
   - Волосы (цвет, длина, стиль)
   - Телосложение и тон кожи

3. **Замена характеристик**: Замена в промпте образца соответствующих элементов:
   - Пол, возраст, раса
   - Черты лица
   - Цвет, длина и стиль волос
   - При смене пола — замена одежды на соответствующую

4. **Генерация**: Создание итогового изображения по финальному промпту

**ВАЖНО**: В модель генерации отправляется только промпт и фото человека, НЕ исходный образец.

## Технологии

- **Анализ изображений**: Google Gemini Vision API
- **Генерация портретов**: Google Imagen API
- **Telegram Bot**: python-telegram-bot
- **Язык**: Python 3.8+

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/ai_portrait_telegram.git
cd ai_portrait_telegram
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте свои API ключи:

```env
# Telegram Bot Token
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Google AI API Key
GOOGLE_API_KEY=your_google_api_key_here

# Optional: Model Configuration
GOOGLE_VISION_MODEL=gemini-1.5-flash
GOOGLE_IMAGE_MODEL=imagen-3.0-generate-001
```

### 5. Получение API ключей

#### Telegram Bot Token

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

#### Google AI API Key

1. Перейдите на [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Создайте новый API ключ
3. Скопируйте ключ в `.env` файл

## Запуск

```bash
python bot.py
```

После запуска бот будет готов принимать сообщения в Telegram.

## Использование

### Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/cancel` - Отменить текущую операцию

### Процесс создания портрета

1. Отправьте боту команду `/start`
2. Отправьте **картинку-образец** (стиль, который хотите применить)
3. Бот подтвердит получение и попросит фото человека
4. Отправьте **фотографию человека**
5. Бот начнет обработку (30-60 секунд)
6. Получите готовый AI-портрет!

### Пример диалога

```
Пользователь: /start
Бот: 👋 Добро пожаловать в AI Portrait Bot!
     Отправьте мне картинку-образец для начала работы.

Пользователь: [отправляет картинку в стиле Ван Гога]
Бот: ✅ Образец получен!
     Теперь отправьте фотографию человека.

Пользователь: [отправляет селфи]
Бот: ⚙️ Отлично! Начинаю работу над портретом...
     Это может занять 30-60 секунд.
     🎨 Создаю ваш шедевр...

Бот: ✨ Готово! Вот ваш AI-портрет.
     [отправляет сгенерированный портрет]
     Хотите создать еще один? Отправьте новую картинку-образец.
```

## Ограничения

- Максимальный размер изображения: 20 MB
- Поддерживаемые форматы: JPEG, PNG
- Генерация портрета занимает 30-60 секунд
- Google API может иметь ограничения по количеству запросов

## Устранение неполадок

### Бот не отвечает

- Проверьте правильность `TELEGRAM_BOT_TOKEN` в `.env`
- Убедитесь, что бот запущен (`python bot.py`)
- Проверьте интернет-соединение

### Ошибки генерации изображений

- Убедитесь, что `GOOGLE_API_KEY` корректен
- Проверьте квоты Google AI API
- Убедитесь, что Imagen API доступен в вашем регионе

### Ошибки анализа изображений

- Отправляйте четкие изображения хорошего качества
- Используйте поддерживаемые форматы (JPEG, PNG)
- Проверьте размер файла (не более 20 MB)
